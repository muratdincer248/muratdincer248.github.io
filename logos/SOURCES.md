Added Nov 22, 2026: ING, İş Bankası, VakıfBank. The Commons files were already cropped to the artwork; `ing.svg` only had its viewBox trimmed to 140.79 wide and its fixed width/height removed. Editor metadata removed, paths untouched.

Added Oct 18, 2026: Garanti BBVA, Unilever, QNB, Algida. Only the viewBox was changed (tight crop) and editor metadata removed; paths are untouched.

`anadolu-efes.svg` was traced with potrace (potracer 0.0.4: alpha upscaled 4× with Lanczos, threshold 50%, `turdsize=8`, `alphamax=1.0`, `opttolerance=0.2`) into one even-odd path. Compared with the source PNG at 1×, no pixel differs by more than half (mean difference 1.2/255, edge anti-aliasing only).

Updated Oct 18, 2026: Haribo replaced with Murat's SVG (no fill, viewBox 110.29 128.59 2279.42 634.88); Nescafé replaced by Nestlé (viewBox cropped to the wordmark, original transform kept).
